## 0. 世界观十二条（序，行 7–42）

判断争议时的底层立场，内化为判断依据即可，不必逐条背诵：

1. 互联网原本是安全的，自从有了做安全的人，也就变得不安全了。
2. 反作弊和作弊都是混口饭吃，攻守易势，没有正邪之分。
3. 某些守方可能更邪恶，因为会使盘外招、报警抓人。
4. 工具是中立的。
5. 决定胜负的不是工具，而是使用工具的人。
6. **所有业务安全风险都是业务制造的。**
7. **业务是皮，风控是毛，皮之不存，毛将焉附。**
8. **守方要守的是博弈均衡，只要破坏博弈均衡，必有问题。**
9. 不知攻，焉知防。
10. 我自堵我的漏洞，与你无关。
11. 百战百胜非善之善者，不战而屈人之兵善之善者也。

## 1. 守护商业模式（第一章，行 43–104）

- 反作弊的对象是**作弊**：非目标用户通过非预期手段窃取目标用户资源，使商业模式实际 ROI 低于预设 ROI。
- 反作弊的使命：保障商业模式长久、稳定地跑通。
- **只有成立的商业模式才具备守护价值**（皮之不存，毛将焉附）。业务最根本的风险是不增长的风险，不是作弊风险。
- 作弊三要素：非目标用户、非预期手段、窃取目标用户资源。

## 2. 四视角理论（第一章，行 71–104）— 技能5方案选择的总纲

降低 I、控制 R、调节 O、改变商业模式，四条路径对应四种视角：

| 视角 | 做法 | 典型代表 |
|---|---|---|
| 玩家视角 | 控制准入资格，只放经过挑选的玩家 | 邀请制/会员制社区 |
| 流程视角 | 流程管控，把异常分支装进笼子 | 注册/发单/取消/打款全审核 |
| 价格视角 | 把风险量化为对价，计入交易成本 | 金融风险定价 |
| 规则视角 | 创造新规则，从源头改变博弈态势 | 业务安全评审、模式创新 |

四个维度排序：

- 最终 ROI：规则 > 流程 > 玩家 > 价格
- 精细度/灵敏度：流程 > 玩家 > 价格 > 规则
- 成本：价格 < 规则 < 玩家 < 流程
- 业务可行性：价格 > 玩家 > 流程 > 规则

**给方案时的使用规则**：单一视角玩到极致都能化险为夷；规则/玩家/流程视角在无专业团队时多半不适用；**初创试水期优先推荐价格视角（风险定价），不要过早投入产研成本做收益未知的反作弊功能**。

## 3. 业务安全评审（第二章，行 127–142）

所有业务安全风险都是业务制造的，但业务不具备领域知识识别它们，因此要事前评审。评审的四个价值：

1. 引入安全专家帮业务充分梳理识别风险点；
2. 优化业务模式，避免承担无意义的风险；
3. 同步现有标准化方案，避免重复造轮子；
4. 深入理解风险实质，利于后续定制化开发。

**领域边界**：反作弊负责维系博弈均衡，业务主导商业模式变革。有内部结算机制的公司反作弊开报价，没有的反作弊有一票否决权。反作弊 = 博弈论工程分支 = 博弈均衡配平术。

## 4. 三流图分析法（第二章，行 143–194）— 技能2/3的理论母体

操作细则已固化在 [../scripts/three_flow_graph_analysis.py](../scripts/three_flow_graph_analysis.py)，此处补理论：

**五要素**：步骤（顺序排布，无次序要求可归一步）、载体（抽象到信息/服务/资金，忽略细节）、角色（抽象交易实体）、流向（发起方→接收方）、操作级别（控制/反制/受制）。

**风险三分法**（配合 [risk-problems-table.md](risk-problems-table.md) 使用）：

- **直接攻击**：发起方/接收方/第三方阻断流程，使其无法正常进行；
- **劫持**：接收方或第三方强使/诱骗发起方，将载体发送到错误对象；
- **伪造**：发起方或接收方伪造载体使步骤通过，但载体并不真正满足步骤预期。

## 5. 四等级安全观（第二章，行 195–210）— 评估"要做到什么程度"

安全等级由业务价值取向决定，反作弊能做的是准确评估并配平。记 B=分支（作弊路径），M=主线（正常路径）：

- **Level 3（理性玩家安全）**：B收益 < B成本，M收益 > M成本 —— 作弊不划算
- **Level 2（羊毛党安全）**：B收益−B成本 < M收益−M成本 —— 作弊不如老实
- **Level 1（黑产安全）**：B收益−B成本−M收益+M成本 < 竞争对手 —— 打我不如打别家
- **Level 0（不安全）**：上述差值 < 现状

注意：安全等级低 ≠ 反作弊做得差。反作弊的价值在于准确预测（如还款能力/意愿），是否冒险放款仍取决于业务价值取向。

## 6. 监管沙盒（第二章，行 211–262）— 平衡创新与风控

模式创新必然冲击博弈均衡。把创新关进小器皿，器皿四特性：

1. **可见性**：足量接口，外界可准确评估运行状况；
2. **代表性**：最大限度还原目标环境，无额外滤网；
3. **易毁性**：失败后可快速销毁，不形成长期维护成本；
4. **不可增殖性**：实验对象不能自我复制扩张冲出器皿。

**适用判定公式**：沙盒工作量 + 补全工作量 × 成功概率 < 一步到位工作量（可简化为：沙盒工作量 < 完整工作量 × 失败概率）。

失控处理：可见性/代表性失效 → 实验无效，终止；易毁性/不可增殖性失效 → 实验失控，立即升级为常规项目重估风险。受控完成后收益正向，三选一：常规重构 / 沙盒补补丁放开限制 / 维持沙盒扩大样本。

## 7. 指标体系（第二章，行 263–306）— 监控方案设计

- **客观指标**（坏账率、拒付率）：以明确业务行为为观察对象，天然适合跨业务横比；鼓励优先使用。
- **主观指标**：无客观标准时靠模型建构，但跨业务移植基本是伪命题。
- **指标三要素**（主观模型必须满足）：**应收尽收**（集合覆盖所有监控对象）、**同升同降**（对象分布变，指标趋势同向变）、**尽可能稳定**（对象不变时指标维持原态势，降误报提信噪）。
- 两类界面不可混用：**业务指标**（异常率、资损率，对接业务决策，受多重因素影响）与**反作弊能力指标**（团队内部评估独立贡献，用比值法/均值法/审核法排除外力）。
