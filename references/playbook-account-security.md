# 领域 Playbook：账号安全

适用场景：涉及注册、登录、KYC、账号体系业务的风险分析。账号安全是所有领域的地基——**兵力有限只能守一个领域时，守账号**。下承移动安全，上启交易/营销/内容安全。需要完整论证时按 [book-index.md](book-index.md) 回溯源文。

## 0. 核心价值与三大战场

账号两性：**唯一性**（一串不重复的数字/字符）与**实人**（用户名/邮箱/手机号背后的真人），一体两面。

兄弟模块对账号安全的三条期许：最小成本过滤最多非目标用户（防暴力破解）；确保操作人始终是持有者（防撞库盗号）；给目标用户赋予高可信标签（识别批量登录、养号）。

三大战场：**账号准入、核身鉴权、关联染色**。

## 1. 账号准入

准入 = 零信任网络中通过信任链证实用户有权使用特定服务。账号成长五阶段：

| 阶段 | 标识 | 能力 |
|---|---|---|
| 无账号 | SecID/TraceID（服务端生成，防 CSRF；Cookie/Session 抗碰撞性差，不推荐） | 阅读协议等免登录操作 |
| 孤立账号 | UserID（登录本质就是核身，可显式可隐式） | 浏览平台基础功能 |
| OpenID | 第三方身份打通（广义含设备指纹、人脸特征），账号进入图谱时代 | 跨平台身份确认 |
| 真身（BindID） | 抗碰撞 + 抗变异（防一人多号），如身份证号、指纹 ID | 实名准入、可疑拦截、自然人限频 |
| 资质审查 | 在 BindID 上打评级/评分标签 | 背景审查、准入门槛判定 |

图谱模型：节点 = SecID/UserID/OpenID/BindID（属性如设备可信度、背调结果）；边 = 关联关系（属性含端版本、验证时间地点、效用"同人/授权/无关"）。**一条有效连接 = 一条信任链；访问服务时校验信任链的规则 = 准入门槛**。

## 2. 账号核身

- **验证网关**：统一收口所有验证调用，避免各业务各自为政。
- **验证策略**：按风险分级匹配验证强度——风险越高验证越强，避免对低风险用户过度打扰（平衡安全性与体验/成本）。

## 3. 账号鉴权

核身解决"你是谁"，鉴权解决"你能做什么"。登录态之后的每次敏感操作都需重新评估权限，不能一次登录终身信任。

## 4. 账号关联

通过图谱边的属性发现批量账号之间的隐藏关联（同设备、同环境、同行为模式），识别养号、批量操作。

## 5. 账号染色

- **黑名单**：命中即严格剔除。来源：内部模型算法 + 外部机构联合惩戒。黑名单管理需谨慎——误伤代价高，需有申诉与退出机制。
- **关联染色**：不止惩罚作恶账号本身，沿图谱边对其关联账号降权/标记，实现"发现一个、带出一串"。
