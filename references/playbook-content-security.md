# 领域 Playbook：内容安全

适用场景：UGC/PGC、评论、IM、直播等内容型业务的风险分析。需要完整论证时按 [book-index.md](book-index.md) 回溯源文。

## 0. 总纲

- 管控对象**不是内容，而是账号**：以内容发现账号，管控于账号；账号成本太低则进一步管控不可变要素（设备、真身）。
- 内容与账号双向绑定的两要素：**采集安全 + 发布安全**。
- 终局思路：内容与账号交替赋能，**将处置收敛到账号**，比在内容上与攻方军备竞赛划算得多。

## 1. 采集安全

目标：内容输入过程确保真人真机实时操作、**所见即所得**。

破坏所见即所得的两种方式：

1. 劫持输入设备，将合法内容替换为非法内容传入网络；
2. 伪造显示设备，骗输入者自以为输入了合法内容。

注意：采集安全**不保证内容本身合法**，职责是把内容与上传者有效绑定，提高任意发布的门槛。落地依赖移动安全基础攻防（如安全相机场景：检测相机 API 是否被劫持，被劫持则不予采集或不予信任）。

## 2. 发布安全

目标：内容输出过程确保违法违规内容不被未经授权者见到。

**先问要不要公开可见**：内容攻击获利与可见范围成正比。SNS/Email/IM 是定向发送，不必冒隐私风险扩大可见范围；电商/O2O 的内容只是交易抓手，盲目广播 = "小业务爆大雷"。

**审核时机两模式**（新 UGC 场景开放之初就必须选定，后期改造伤体验）：

| 模式 | 要求 | 适用 |
|---|---|---|
| 先发后审 | 需具备防扩散和撤回能力 | 小成本制作、高时效内容、高质量生产者 |
| 先审后发 | 对处理时效有要求（内容有保鲜期） | PGC、广告等制作成本高传播广的内容、低质量生产者、低时效内容 |

**文本审查三路线**（实践综合运用）：

| 路线 | 原理 | 优劣 |
|---|---|---|
| 敏感词 | 直接匹配 | 简单可解释，但极易绕过；价值在于锁定种子用户、随对抗迭代发现新规律 |
| 正则 | 纯文本扫描 | 适合可预测遍历的内容（如数值型），通用性强 |
| NLP | 自然语言→高维向量 | 依赖分词，效率高但损失细节；子类**情感分析**可识别发言攻击性；NLG 可用于反向评测 NLU 理解是否准确 |

图像/音频/视频多模态审查以文本判定为基础（同样识别为高维向量）。图像表意两方式：图上文字、画面客体与意境。

**识别结果三种返回格式**：判定（只报有无）、标记（列出异常内容）、替换（替换为预设内容）。对应图像领域 = 仅检测 / 检测并框选 / 检测并马赛克。
